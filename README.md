# 🎨 Painting Website

A simple, interactive painting website that allows users to draw on a digital canvas with various tools, colors, and brush sizes. Built using HTML, CSS, and JavaScript with a clean and responsive UI.

## 🌟 Features

- 🖌️ Freehand drawing on canvas  
- 🎨 Multiple brush colors  
- 📏 Adjustable brush size  
- 🪣 Fill option for shapes  
- 🧽 Clear the canvas  
- 💾 Save your artwork as an image  
- 📱 Responsive design for mobile & desktop  
- ⚡ Smooth UI/UX with custom and Tailwind styling
